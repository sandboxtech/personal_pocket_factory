# 戴森环计划

异星工厂（Factorio 2.0 + 太空时代）多人服务器玩法。

**每人一条专属戴森环，永不重置，但一颗矿都没有。**
**资源全在五个公共星球上，而那些星球隔一两个小时就整颗清空。**
**吃科技瓶，增加自己的戴森环长度**
---

## 戴森环

你的私人平面，只有你能进，**永远不会重置**。

- 环里**没有任何矿产**，中间有一小片浅水（可以架海洋泵，走得过去）
- 高度固定 128 格，宽度随经验增长
- 死亡后一律在自己环里复活

## 十二种经验

12 种科技瓶各记各的账。**每种经验的十进制位数就是它给的级数**，12 项相加是总等级。

| 这种经验攒到 | 它给的级数 |
| --- | --- |
| 1 ~ 9 | 1 |
| 10 ~ 99 | 2 |
| 100 ~ 999 | 3 |
| 每再翻十倍 | 再 +1 |

一点都没攒过的那种算 **0**，所以五个星球都得跑到。

```
戴森环宽度 =（总等级 + 2）× 32 格
飞船宽度   =（总等级 + 4）× 16 格
```

## 关联箱

**手搓木箱做出来的直接就是关联箱**（组装机产的木箱放下去也会变）。

- 放在戴森环**之外**就是投递口，塞进去的货直通你环里的收货箱
- **全宇宙同时只能放一个**。放新的时，旧的自动退回你的背包
- 箱子**谁都打不开**，进出全靠机械臂

## 体力与兑换

体力每秒恢复 1 点，**离线也恢复**，攒满即停。**1 点体力兑换 1 个科技瓶。**

- **手动兑换**：点 HUD 上的「我的戴森环」，吃**背包**里的瓶子，兑换前有预览
- **自动兑换**：在线时每分钟一次，离线时每十分钟一次，吃**收货箱**里的瓶子

两者**共用同一池体力**。想留瓶子做研究，就赶在下一轮自动兑换之前用机械臂拉走。

## 公共世界

五个星球各有各的重置周期，到点整颗星球清空，你留在上面的东西一起没。

| 星球 | 重置周期 |
| --- | --- |
| Nauvis | 60 分钟 |
| Vulcanus | 120 分钟 |
| Fulgora | 180 分钟 |
| Gleba | 240 分钟 |
| Aquilo | 300 分钟 |

五个周期互相错开，任何时刻都有刚重置的新世界和快到期的成熟世界。矿脉尺寸比原版大得多（面积 6 档、储量 4 档），因为世界寿命短，按原版尺寸建设时间会吃掉整轮的大半。

## 科技漏水

已研究的科技会定期被撤销，**概率随该科技需要的瓶子种类数上升**（大约 = 种类数 %）。

- 越靠后的科技漏得越快，地基科技最稳
- **等级科技退一级，不清零**
- 触发式科技永不丢失

## 飞船

- 在「全服」页面登记一艘，**以你的名字命名，每人同时只有一艘**
- 登记之后仍需照常**用火箭把太空平台起步包发射上去**，船才真正成形
- 寿命 **50 小时**，到点自动销毁
- 可以在「全服」页面主动拆掉自己的船（两步确认），拆了才能建新的
- 飞船全服公有：**谁都能登船**，但只有船主能拆

## 长期不上线

| 离线时长 | 会发生什么 |
| --- | --- |
| 满 30 小时 | 戴森环转为**公共**，任何人可进、可拆、可搬空 |
| 满 50 小时 | 戴森环被**回收** |

新人的两个阈值按累计在线时长缩放（投入多久就受多久保护），下限 1 小时。

**经验永远不受影响**，回来点一下回环按钮，环按经验重新长回原来的宽度。

## 界面速查

屏幕左上角：

- 第一行六颗图标：一键传送到自己的戴森环 / 五个公共星球
- 第二行：等级、体力，以及四颗按钮

| 按钮 | 内容 |
| --- | --- |
| 我的戴森环 | 体力、兑换、12 项经验明细 |
| 全服 | 所有人的戴森环和飞船，也在这里建船 / 拆船 |
| 传送 | 带重置倒计时的完整传送列表 |
| 玩法 | 规则说明（在线满 6 小时后会多显示具体数值） |

## 管理员指令

| 指令 | 作用 |
| --- | --- |
| `/pw-config` | 打开参数窗口：所有可热改的值、改完何时生效、各自什么意思 |
| `/ring-delete <玩家名>` | 删掉某人的戴森环（经验不受影响） |
| `/ring-delete-all [confirm]` | 重置全服戴森环。不加参数只看预览 |

参数改法：`/sc storage.名字 = 新值`。`/pw-config` 里每项都标了生效范围——绿色立刻全服生效，黄色要等特定时机（下次重置 / 只对新建的东西），灰色目前不起作用。
