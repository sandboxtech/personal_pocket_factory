# 戴森环计划

异星工厂（Factorio 2.0 + 太空时代）多人服务器玩法。

**每人一条专属戴森环，不随星球重置，但一颗矿都没有。**
**资源全在五个公共星球上，而那些星球隔两到七个小时就整颗清空。**
**吃科技包，增加自己的戴森环长度**

## 戴森环

你的私人平面，只有你能进。公共星球每隔几小时整颗清空，**戴森环不参与那套重置**——只要偶尔上线，它就一直是你的。

- 环里**没有任何矿产**，中间有一小片 4×4 浅水（走得过去；四面岸上都能架抽取泵）
- 8 个收货箱**横排**成上下两行，夹着中间的水池（和水池之间各留 2 格岸）；机械臂从箱阵外侧（上下两面）取货
- 高度固定 **32 格**：中间 16 格可建，上下各 8 格临空。宽度随经验增长
- **永昼**，太阳能板 24 小时满出力，不用蓄电池也不会半夜停摆
- 死亡后一律在自己环里复活，且**每 3 小时至多补发一套起始装备**（模块装甲 + 个人机器人指令模块 + 6 块太阳能板 + 10 个建设机器人，装备直接穿好插好，机器人在背包里）
- **唯一会失去它的方式是长期不上线**：先转公共任人拆解，再久才被回收（见下面「长期不上线」）。经验永远不受影响

## 十二种经验

12 种科技包各记各的账。**每种经验的十进制位数就是它给的级数**，12 项相加是总等级。

| 这种经验攒到 | 它给的级数 |
| --- | --- |
| 1 ~ 9 | 1 |
| 10 ~ 99 | 2 |
| 100 ~ 999 | 3 |
| 每再翻十倍 | 再 +1 |

一点都没攒过的那种算 **0**，所以五个星球都得跑到。

```
戴森环宽度 =（总等级 + 4）× 16 格
飞船宽度   =（总等级 + 4）× 16 格
```

## 关联箱

**手搓木箱做出来的直接就是关联箱**（组装机产的木箱放下去也会变）。

- 放在戴森环**之外**就是投递口，塞进去的货直通你环里的收货箱
- **全宇宙同时最多 8 个**。放第 9 个时，**最早放下的那个**自动退回你的背包
- 箱子**谁都打不开**，进出全靠机械臂

8 个名额是全宇宙合计，不按星球平摊——全铺开覆盖五颗星球，还是把好几个堆在刚重置完的那颗上抢一轮产出，你自己权衡。

## 体力与兑换

体力每秒恢复 1 点，**离线也恢复**，攒满即停。**1 点体力兑换 1 个科技包。**

- **手动兑换**：点 HUD 上的「我的戴森环」，吃**背包**里的瓶子，兑换前有预览
- **自动兑换**：在线时每分钟一次，离线时每十分钟一次，吃**收货箱**里的瓶子

两者**共用同一池体力**。想留瓶子做研究，就赶在下一轮自动兑换之前用机械臂拉走。

## 公共星球

五个星球各有各的重置周期，到点整颗星球清空，你留在上面的东西一起没。

| 星球 | 重置周期 |
| --- | --- |
| Nauvis | 120 分钟 |
| Vulcanus | 180 分钟 |
| Fulgora | 240 分钟 |
| Gleba | 300 分钟 |
| Aquilo | 420 分钟 |

重置前 **5 分钟和 1 分钟**会提醒还站在那颗星球上的人（半路降落的也会单独收到剩余时间）。

五个周期互相错开，任何时刻都有刚重置的新世界和快到期的成熟世界。每颗星球重置时，它自己的产量/击杀/建造统计一并归零，**戴森环里的曲线不受影响**。矿脉尺寸比原版大得多（面积 6 档、储量 4 档），因为世界寿命短，按原版尺寸建设时间会吃掉整轮的大半。

**每颗星球的矿种不变**：只有本来就产在那儿的资源被调大，废料仍然只有 Fulgora 有，钨和方解石仍然只有 Vulcanus 有。

## 科技漏水

已研究的科技会定期被撤销，**概率随该科技需要的瓶子种类数上升**。

每一轮先掷一个 **0 ~ 2 的系数**，这一轮所有科技共用它：某科技被撤销的概率（百分比）= 瓶子种类数 × 该系数。所以有的轮次风平浪静，有的轮次成片地掉，平均下来约等于「种类数 %」。

- 越靠后的科技漏得越快，地基科技最稳
- **等级科技退一级，不清零**
- 触发式科技永不丢失

## 飞船

- 在「全服」页面登记一艘，**以你的名字命名，每人同时只有一艘**
- 登记之后仍需照常**用火箭把太空平台起步包发射上去**，船才真正成形
- 寿命 **50 小时**，到点自动销毁
- 可以在「全服」页面主动拆掉自己的船（两步确认），拆了才能建新的
- 飞船全服公有：**谁都能登船**，但只有船主能拆

## 长期不上线

| 离线时长 | 会发生什么 |
| --- | --- |
| 满 3 ~ 30 小时 | 戴森环转为**公共**，任何人可进、可拆、可搬空 |
| 再过 3 倍时长（9 ~ 90 小时） | 戴森环被**回收** |

两个阈值都按累计在线时长缩放——**投入多久，就受多久保护**。全新玩家是 3 小时转公共、9 小时回收；累计在线满 30 小时之后封顶在 30 小时和 90 小时。

转公共之后，你的环会**顶着你的名字**出现在遥控视角左侧的平面列表里，谁都能点进去看。私人期间它是隐藏的。

**经验永远不受影响**，回来点一下回环按钮，环按经验重新长回原来的宽度。

## 管理员指令

| 指令 | 作用 |
| --- | --- |
| `/pw-config` | 打开参数窗口：所有可热改的值、改完何时生效、各自什么意思 |
| `/ring-delete <玩家名>` | 删掉某人的戴森环（经验不受影响） |
| `/ring-delete-all [confirm]` | 重置全服戴森环。不加参数只看预览 |
| `/pw-repair` | 修复：补齐缺失的配置、重建权限组、补建世界、校准所有环。幂等，随时可执行 |
| `/pw-reset-config [confirm]` | 把所有参数推回默认值（玩家进度不动）。不加参数只看预览 |
| `/pw-export` | 导出所有玩家的经验和体力到 `script-output` |
| `/pw-import [confirm]` | 从 `exp_import.lua` 恢复经验和体力。不加参数只看预览 |

**热更新脚本后请执行一次 `/pw-repair`**：`game.reload_script()` 不触发 `on_init` / `on_configuration_changed`，新版本新增的配置字段和初始化步骤不会自动跑。

起手物资和起始装备都可以改，`/pw-config` 里直接显示当前发的是什么：

```
/sc storage.starter_items = {{name='iron-plate',count=500}}
/sc storage.starter_equipment = {{name='modular-armor',count=1},{name='solar-panel-equipment',count=6}}
/sc storage.starter_equipment_hours = 3
```

`starter_equipment` 里**带装备栏的装甲要排在前面**——发放时先把第一件这样的装甲穿上，后面的模块才有地方插。

### 导出 / 导入玩家进度

`/pw-export` 会在 `script-output` 里写两个文件：

- `pw-progress-<tick>.json`——给人看、给外部工具用
- `exp_import.lua`——**这个就是导入文件**，直接复制进 scenario 目录（和 `control.lua` 同级）即可，不用改名

导入要三步，因为**引擎没有运行时读文件的 API**，脚本读磁盘只有「加载阶段 `require`」这一条路：

```
1. 把 exp_import.lua 复制进 scenario 目录
2. /c game.reload_script()     ← 这一步才真正把文件读进来
3. /pw-import                  ← 预览：几名玩家、几个能对上号、忽略了几个坏字段
4. /pw-import confirm
```

导入是**覆盖不是合并**：文件里那些玩家的经验和体力被整个替换，没提到的玩家不受影响。文件里出现的陌生名字不算错——storage 按玩家名索引，人进服时自然对上号，所以可以在开服前先把老数据导进去。

体力导出的是**点数**而不是内部的 tick，跨服务器搬运时不受 `stamina_ticks_per_point` 差异影响；恢复时间戳一律重置为当前时刻。

参数改法：`/sc storage.名字 = 新值`。`/pw-config` 里每项都标了生效范围——绿色立刻全服生效，黄色要等特定时机（下次重置 / 只对新建的东西），灰色目前不起作用。
